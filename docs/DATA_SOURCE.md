# Dataset provenance

Worldline and the Machine Learning Group, Université Libre de Bruxelles. Credit Card Fraud Detection dataset, originally published via Kaggle.

284,807 original transaction records, including 492 labelled frauds, with anonymised PCA features, relative time and transaction amount.

- Original source: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
- Acquisition endpoint used: https://storage.googleapis.com/download.tensorflow.org/data/creditcard.csv
- Acquired: 25 October 2026.
- SHA-256 of extracted/received source file: `76274b691b16a6c49d3f159c883398e03ccd6d1ee12d9d8ee38f4b4b98551a89`.

The original Kaggle listing labels its data terms "Database: Open Database, Contents: Database Contents". Consult the original listing for the governing Open Data Commons terms; the code MIT licence does not replace them. Raw data and row-level scored outputs are not redistributed. Aggregate reports and figures acknowledge the original creators. The CSV download is the public mirror explicitly used by the official TensorFlow tutorial: https://www.tensorflow.org/tutorials/structured_data/imbalanced_data.

The original file is read without modifying its bytes. Feature engineering, split assignment, deduplication policies, probability calibration and aggregate outputs are adaptations documented in the protocol. No private employer or user banking data is used. Checksum or shape changes cause the analysis to stop for review rather than silently accepting a different dataset.
